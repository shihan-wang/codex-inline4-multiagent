# V3 阶段 1：独立机械与运动学只读审查

## 结论

当前 v2 基线在四冲程数学、1-3-4-2 顺序、1/4 与 2/3 曲柄相位、曲柄连杆闭合、5.5 mm 顶隙、凸轮半速、逐缸喷油与热释放分离方面没有发现 P0/P1 回归。真实页面稳定、控制完整、核心运动链易于理解。

本轮从当前提交重新检查后，仍发现 3 个 P2 高价值问题：配气机构只在运动相位上对齐、接触与阀座几何不闭合；所有流线被统一强制闭环并且进排气不按缸/气门相位驱动；负载不改变喷油可视量。前两项直接影响机械可信度和系统可读性，属于“明显、高收益但成本不全是低”的候选；第三项是高收益、低成本候选。

## 缺陷清单

### M-01 — P2：配气运动相位正确，但凸轮—挺柱—弹簧—阀座接触链没有几何闭合

- 实际证据：`src/scene/assembly.ts:364-389` 把阀组基准放在 `y=280`，阀头厚 5 mm、弹簧高 36 mm、挺柱中心 `y=75`；`395-416` 用缩放球体作偏心凸轮，只把鼻端在最大升程相位朝向挺柱。`777-787` 的阀行程是 11/10 mm，而弹簧缩放分母固定为 45。独立确定角度计算得到：关闭阀面最低点比缸盖面内缩 8.5 mm；弹簧最大升程时顶端比挺柱顶高 2.2 mm；进气启闭相位凸轮表面穿入挺柱约 3.476 mm，峰值仍穿入约 0.5 mm。`desktop-valvetrain.png` 的近景实际显示了该机构，故并非纯源码理论问题。
- 质量影响：慢速、暂停和配气相机下，用户看到的是“同步旋转的凸轮”和“按函数平移的阀”，不是能连续传力的接触机构；阀面也没有在缸盖/燃烧室边界清楚落座，降低剖切机械可信度。
- 预计收益：高。让核心配气链从相位演示提升为可目视验证的机械闭合，尤其改善暂停、剖切和配气近景。
- 实现成本：中（约 0.5–1.5 人日）。需要统一基圆/鼻端径向轮廓与挺柱轨迹、阀长/阀座平面、弹簧实际 36 mm 端点。
- 风险：中。重新定位可能引入凸轮轴承、缸盖或活塞干涉，并改变相机构图；必须以逐角度扫掠检查。
- 可验证验收：在开阀、峰值、关阀三个确定角度，凸轮与挺柱间隙/穿透落在可声明的冷态间隙容差；关闭阀面与缸盖阀座平齐；弹簧固定端不动且运动端始终与挺柱/保持器同位；720° 浏览器慢放无跳变和穿模。

### M-02 — P2：油、冷却、进气流线被强制闭环，进排气效果没有按缸和气门时序驱动

- 实际证据：`src/scene/effects.ts:52,64` 对每个 `FlowPath` 无条件使用闭合 Catmull-Rom 与闭合 Tube。进气点列在 `src/scene/assembly.ts:649-665` 从涡轮压气机到进气系统末点，却因闭环额外直连回第一点，形成不存在的可视回流；冷却点列 `629-646` 串行穿过各缸并闭回，油路 `608-626` 只有一条总线。`src/scene/effects.ts:120-155` 的 10 个排气脉冲沿一条固定通道连续移动，`assembly.ts:801-805` 只接收全局 RPM/负载 activity，没有任一缸的排气阀或冲程状态。
- 质量影响：开启流体图层后，方向和系统关系可能比关闭时更误导：空气会沿虚拟闭合段返回压气机，排气在四缸均关闭/未排气时仍连续出现，润滑与冷却也没有表现主油道/水套的分支供给。
- 预计收益：高。让流体层真正解释“当前哪缸进/排气、介质如何供给与回流”，显著增强系统教学价值。
- 实现成本：中高（约 1–2 人日）。需要支持开放路径和分支路径，并按缸驱动进/排气发射；可复用几何与实例粒子控制 draw calls。
- 风险：中高。分支粒子会增加画面拥挤与 draw calls；状态触发不做滞后会闪烁。
- 可验证验收：进气和排气不含末点到首点的虚拟直线；只有进气阀打开的缸显示进气支路，只有排气阀打开/排气冲程的缸显示排气脉冲；油从油底壳/泵/滤清器分到主轴承、连杆、凸轮和涡轮再回流；冷却具有泵→缸套/缸盖→回水的连续路径；120 帧 draw calls 不明显恶化。

### M-03 — P2：负载滑块不改变逐缸喷油可视量

- 实际证据：`src/scene/assembly.ts:790-798` 的燃烧发光强度含 `snapshot.load`，但喷油锥透明度固定为 `injection * 0.78`，几何尺度与粒子量也不读负载。机械审查测试证明喷油命令与热释放时间已正确分离，所以问题不是相位，而是燃油量表达。
- 质量影响：同一转速和曲轴角下，0% 与 100% 负载的喷油锥相同；用户难以从关键执行器看出负载控制的物理含义。
- 预计收益：中高，且成本低。负载交互获得直接、逐缸、易懂的视觉反馈。
- 实现成本：低（约 0.25–0.5 人日）。用带最小怠速量的负载因子控制锥体角度/长度/透明度或实例粒子数。
- 风险：低。负载为零时不可让怠速喷油完全消失，也不应把锥体变大误表达喷射压力必然升高。
- 可验证验收：固定 RPM 和同一喷油角度，对 0/50/100% 负载拍三张确定角度截图；喷油持续相位保持不变、可视燃油量单调增加、0% 仍保留怠速最小量，热释放强度与其一致。

### M-04 — P3：整数曲轴角显示与严格冲程边界可在一帧内看似矛盾

- 实际证据：`src/engine/kinematics.ts:103-109` 在 180/360/540° 使用严格边界分类；实际 `narrow-390x844.png` 显示整数 `180°` 时，四缸状态仍是前一侧边界状态，说明角度文本四舍五入而状态使用未舍入内部值。
- 质量影响：用户在暂停或窄屏读数时会看到“180° 但仍是做功”等一帧歧义，容易误判四冲程边界错误。
- 预计收益：中。消除一个会伤害正确核心算法可信度的展示细节。
- 实现成本：低（<0.25 人日）。显示一位小数，或对角度文本和状态使用同一快照/边界取整策略。
- 风险：低。避免为了显示而改变真实运动状态。
- 可验证验收：确定设置 179.9/180.0/180.1°，文本与冲程状态一致；对 0/360/540/720° 同样检查。

### M-05 — P3：凸轮半速在数值上正确，但没有可见的曲轴—凸轮定时驱动

- 实际证据：`src/scene/assembly.ts:753-756` 直接把两凸轮轴旋转设置为曲轴一半；实际 `desktop-valvetrain.png` 近景能看到双凸轮，却没有齿轮、链条或皮带把它们与曲轴连接。
- 质量影响：用户可以看出凸轮会转，却无法从模型理解 2:1 关系如何机械建立；在爆炸/配气预设下尤明显。
- 预计收益：中。把目前只存在于状态逻辑的半速关系变成可视机械关系。
- 实现成本：中（0.5–1 人日）。前端增加曲轴齿轮、两倍齿数凸轮齿轮和简化链/带，并与现有相位绑定。
- 风险：中。会增加前端拥挤、几何量和 draw calls，链条无需逐链节模拟。
- 可验证验收：手动转曲轴两圈，凸轮齿轮恰好一圈，链/带无明显滑移或穿模；相机预设能读出 2:1 齿数/直径关系。

### M-06 — P3：涡轮转子和排气能量关系只做了全局动画近似

- 实际证据：`src/scene/assembly.ts:511-555` 的排气歧管→涡轮→共轴压气机→进气管几何拓扑正确；但 `757` 用 `max(8, rpm*0.075)` 直接旋转转子，`801-805` 的排气脉冲只由全局 RPM×负载驱动，不含缸压/阀门或合理的涡轮滞后。以 1800 RPM 为例，动画约 135 rad/s（约 1289 rpm），不能作真实涡轮转速解读。
- 质量影响：低负载、高转速和瞬态时，转子/排气/进气流之间缺少可理解的因果关系；若把动画速度当数值会被误导。
- 预计收益：中低。增强增压系统反馈，但不如配气闭合和流路修复直接。
- 实现成本：中（0.5–1 人日）。建立无量纲 spool 状态、惯性与废气能量输入，不宣称物理 RPM。
- 风险：中。参数不校准仍会产生“伪精确”；应明确是归一化演示模型。
- 可验证验收：固定 RPM 下负载阶跃后转子/进气流平滑滞后上升，卸载平滑衰减；无瞬时跳变；界面不把视觉角速度标成实际涡轮 RPM。

## 已验证无误项

1. **点火顺序和相位**：配置为 1-3-4-2，发火 TDC 分别为缸 1/3/4/2 的 0/180/360/540°。
2. **曲柄配对**：1/4 相同 throw phase，2/3 相同且相对 180°；实际页面的剖切与曲柄相机可见成对活塞位置。
3. **四冲程定义**：单缸以发火 TDC 为 0°，0–180 做功、180–360 排气、360–540 进气、540–720 压缩；四缸按发火相位平移。
4. **曲柄连杆闭合**：滑块曲柄使用精确根式解；确定角度扫描闭合误差不超过 `2.49e-16 mm`，连杆实际每帧由大头至活塞销重算长度与姿态。
5. **顶隙**：TDC 活塞冠至缸盖面为 `5.5 mm`。
6. **凸轮半速和逐缸峰值相位**：凸轮旋转严格为曲轴的 1/2；每缸进、排气凸轮鼻端峰值相位与阀升程峰值一致。M-01 仅说明连续接触几何仍未闭合。
7. **喷油与热释放分离**：喷油命令约 710°–20°，可视热释放延续至 75°；10° 同时存在而 45° 只剩热释放。
8. **阀时序重叠**：进气 345° 开/580° 关，排气 135° 开/375° 关，气体交换 TDC 前后具有适度重叠；页面逐缸状态与源码一致。
9. **阀弹簧固定端方向**：当前变换确实保持弹簧下端在局部 `y=42`；M-01 扣分来自运动端与挺柱/保持器相差 2.2 mm，而不是固定端随动。
10. **增压管路的宏观方向**：四个排气支管汇入涡轮热端，转子共轴连接压气机，压气侧管路进入进气总管，下游另有排气管；拓扑主体正确。
11. **浏览器交互与模式**：实体、X-Ray、剖切、曲柄、配气和窄屏均真实打开；暂停、转速/负载、切换、相机、选择、旋转、缩放、平移通过验收。

## 权威资料交叉检查、参数与简化假设

1. [Colorado State University — Slider-Crank Model](https://www.engr.colostate.edu/~allan/thermo/page2/page2.html)：采用曲柄半径为冲程一半、TDC 为 0° 的滑块曲柄几何；与当前精确闭合公式一致。
2. [NASA Glenn — Four Stroke Internal Combustion Engine](https://www.grc.nasa.gov/WWW/K-12/BGP/engopt.html)：四冲程气体分别经进、排气阀交换，凸轮轴由曲轴定时并以曲轴两圈/凸轮一圈工作；用于核对半速、气门因果关系和 M-02/M-05。
3. [Yanmar — 4MP107](https://www.yanmar.com/in/about/company/yebisu/4mp107/)：公开的直列四缸四冲程柴油机使用 1-3-4-2、涡轮中冷、水冷和强制湿式润滑；用于交叉核对架构而非声明本模型复刻该机。其 0.3/0.4 mm 阀隙仅作数量级参照，不把它当成本代表模型的精确阀隙。
4. [Bosch Mobility — Common-rail system with solenoid injectors](https://www.bosch-mobility.com/en/solutions/powertrain/diesel/common-rail-system-solenoid/)：共轨作为蓄压器供给各缸喷油器，控制器逐缸计算喷油开始和燃油量；用于核对逐缸喷油和 M-03 的负载—可视量关系。Bosch 页面最高 2500 bar 不用于替换本模型声明的 1600 bar。
5. [Cummins — How a turbocharger works](https://www.cummins.com/en-apac/components/turbochargers/how-a-turbocharger-works)：排气驱动涡轮，共轴带动压气机并把压缩空气送入发动机；当前宏观几何符合，M-06 仅针对动画因果近似。
6. [Cummins — Lubricating Oil System Flow Diagram](https://mart.cummins.com/imagelibrary/data/assetfiles/0057076.pdf) 与 [Cummins — Main oil rifle / turbo supply diagram](https://mart.cummins.com/imagelibrary/data/assetfiles/0057319.pdf)：油从油底壳经泵和滤清器供给运动件、轴承、凸轮及涡轮并回流；用于判断 M-02 单条闭合流线不足以表达主要分支。

审查采用以下明确假设：这是可编辑的“代表性现代紧凑工业直四柴油机”，不是某一量产机的数字孪生；凸轮与涡轮可以为浏览器性能做视觉简化，但不应在近景出现明显穿插或把闭合回路画成不存在的流向；流体粒子不要求 CFD 精度，但必须保持方向、分支和逐缸时序不与机械状态冲突；软件渲染帧率只用于同环境回归，不用于普通电脑性能结论。

## 候选改进排序

1. **M-01 配气接触链闭合**：机械可信度收益最高；中成本、中风险。
2. **M-02 开放/分支流路并按缸驱动进排气**：系统解释收益高；中高成本、中高风险。
3. **M-03 负载改变可视喷油量**：中高收益、低成本、低风险，是本轮最明确的快速收益。
4. **M-04 角度/冲程边界显示一致**：中收益、极低成本。
5. **M-05 增加简化定时传动**：中收益、中成本；需控制几何和 draw calls。
6. **M-06 涡轮惯性与排气能量耦合**：中低收益、中成本，适合在核心两项之后。

是否仍有明显高收益项：**有**。M-01、M-02 明显且高收益但成本分别为中/中高；M-03 是高收益、低成本。建议实现阶段优先 M-01 与 M-03；若额度/性能预算允许，再以开放路径 + 每缸少量实例粒子的最小方案处理 M-02。
