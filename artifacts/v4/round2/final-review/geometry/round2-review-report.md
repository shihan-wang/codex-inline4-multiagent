## 解析根因判断

当前实现先从 `crankWebGeometry()` 顶点计算绕曲轴 X 轴的二维 Y/Z 最大扫掠半径，再把定位环内半径 44 mm 代入勾股关系，得到定位环中心高度。这个约束忽略了实际三维横向关系：

- 每片 web 的中心位于缸心 X±31 mm；
- web 本身沿 X 还有厚度；
- Torus 定位环和圆柱缸套的边界由 X/Z 径向共同决定；
- 因此仅用 Y/Z 扫掠半径和“内半径 44 mm”不能保证 web 三角面与环面/圆柱面分离。

BVH witness 正好落在缸套/定位环径向边缘，并在两类目标上给出相近连续角窗，验证了这一错误投影。下一修复不应继续经验增加一个标量余量；应从完整 web 顶点/三角形在其实际 X 偏置下求保守三维扫掠边界，或直接由几何约束推导缸套下缘和定位环高度，再以全扫描为最终验收。
