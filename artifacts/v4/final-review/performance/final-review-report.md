## 放行结论

**本独立方向建议放行。** 本轮未发现 P0、P1，也没有发现无法解释的视觉或性能回退。Intel Arc 的正式持续门、正向浏览器验收、负向故障夹具、类型检查、27 项单测和生产构建均通过；分解视图的 V3 裁切缺陷在同尺寸、同角度 V4 画面中已经修复。

放行边界：这只是视觉/性能/测试方向，不能替代机械几何和无障碍独立审查；也不代表真人 NVDA 或真人盲评。

## 为什么没有重跑 Spector

这是预注册规则下的技术判断，不是漏测：

- V4 没有修改材质模块或 WebGL renderer/tone-mapping/shadow 管线；`src/scene/index.ts` 的渲染相关变化是分解状态相机目标。
- 正式烟测 draw 仅增加约 0.37%，持续 draw 仅增加约 0.38%，没有出现材质/program/draw 结构的显著变化。
- 因此没有触发“材质、管线或 Draw Calls 明显变化才重跑 Spector”的条件；昂贵 V3 捕获未被覆盖。

## 缺陷分级

### P0：0

无。

### P1：0

无。浏览器、控制台、构建和冻结的硬件性能门均未发现阻断问题。

### P2：2 个已解释限制

1. **继承的移动冷缓存性能债**：V3 外部测评的移动 LCP 中位 3458 ms、最大 5968.5 ms。本轮没有运行完整 V4 5 次移动冷缓存协议，所以不能推断其已改善。V4 构建 JS 相对 V3 608.48 kB 增至 614.18 kB，约 +0.94%；没有证据表明发生明显启动回退，但也没有完整 Lighthouse 数据证明持平。保留为后续专门性能工作，不阻断本次由几何/无障碍证据驱动的 V4。
2. **SwiftShader 仍非流畅路径**：V4 实测 11.41 FPS、p95 100.1 ms；功能和稳定性通过，但只可称为兼容，不可称为普通浏览器实时体验。Intel Arc 独立达到 120 FPS 级，故不以牺牲硬件画质降级来刷软件帧率。

### P3：2 个非阻断项

- Vite 仍提示 614.18 kB 主 JS 大于 500 kB；gzip 162.31 kB。需要未来以启动剖析驱动拆包，不能仅为消警告盲拆。
- 两次 Puppeteer 确定性截图尝试在评估器启动路径报 `Access denied`/超时；失败证据完整保留。切换到与 V3 基线一致的原始 CDP 方法后第三次成功，HTTP 页面、renderer、控制台和画面均正常，因此这不是产品缺陷。

## 实测、判断、推断与未测

- **实测**：类型检查、27 项测试、构建、正负向浏览器、两条持续 WebGL、四张固定 V4 画面、renderer、控制台和截图状态。
- **审查判断**：没有视觉退化；分解构图缺陷已修；Spector 未触发；本方向放行。
- **推断**：约 1% 的 JS 体积变化和 <1% draw 变化本身不显示显著启动/单帧命令回退；该推断不能替代 Lighthouse/Spector 实测。
- **未测/待真人**：V4 现场 INP p75、完整 5+5 Lighthouse、未触发的 V4 Spector、真人 NVDA、真人盲评。

## 最终建议

视觉/性能/测试方向 **approve**。没有可行且明显高收益的未处理视觉或硬件性能回退；保留的 P2 都有实测边界和不实施理由。全局 V4 是否最终提交，应再以独立机械几何和无障碍审查结论为共同前提。
