## 结论

固定对象为 `7e5ea916a115dcef1bf3ba467a31b78c6206c612`。本代理未修改 `src/`、`docs/`、Git 状态或既有 `artifacts/external-eval/`；全部新增内容只在本目录。

## 四类裁决标准

1. **外壳预期包裹**：内部零件位于外表面之内，本身不能证明碰到材料。
2. **合理接触或间隙**：有设计依据的配合；本轮重点缺陷中没有用此类消除任何结果。
3. **扫描器/语义限制**：AABB、48 点稀疏采样、父级名称或把外壳当完整实体导致的误报、漏报或不可归因。
4. **确认真实穿透**：Blender BVH 返回实际导出三角面相交对。

同一 pair 可以是混合裁决。例如“活塞 vs 外壳”在多数角度只是处于外壳里面（1/3），但在上止点附近又确实穿过没有缸孔的顶封口面（4）。

### 721/721 的根因

冻结扫描把主缸体外表面当成填满的闭合实体，再以 48 个表面见证点判断“在里面”。因此每个活塞、连杆和曲轴在全部角度都被报碰撞；这部分混入大量第 1/3 类结果。

但不能因此撤销总故障：独立窄相确认曲轴与没有曲轴箱空腔的主缸体导出表面在 **721/721** 角度相交；活塞穿过没有四个缸孔的顶部封口面，连杆穿过底部封口面。因此装配级 721/721 仍是实际 P1，只是原扫描不能正确量化每个 pair 的真实相交角数。

### `107 mm` 的正确解释

`107 mm` 是“被判在闭合外壳内部的稀疏见证点，到最近外部三角面的最大距离”。它可能只是零件深处于预期外轮廓内部；没有构造主缸体材料的内表面，也没有计算两个闭合材料体的最小分离向量。因此它不是穿透深度，量值本身属第 1/3 类。

与此同时，Blender 的独立面相交证明缺失空腔确有真实后果，所以结论不是“全为误报”，而是“深度代理无效，但表面穿模成立”。

### `21.413884 mm` 的正确解释

该值是轴向位于缸套范围内的 48 个连杆见证点，其径向距离超出理想 44 mm 缸套半径的最大值。它不是沿缸套表面法线求得的接触深度，也不是实体体积重叠深度。48 点探针报 268 个角，而完整三角面 BVH 报 272 个角，说明稀疏采样略漏报。

实际相交仍成立：四个 pair 各有四段连续相交窗口，且 1/4 缸、2/3 缸的相位分组一致。V4 应根据完整 720° 连杆扫掠包络设计缸套下端避让，而不是任意缩短缸套或缩小连杆。

## 曲轴、平衡重、轴颈、正时与附件覆盖

冻结扫描把 44 个语义曲轴节点拼成一个 mesh，再为整个总成只选 48 个最远点。精确重放样本选择并按坐标回溯节点得到：

| 角色 | 节点覆盖 |
|---|---:|
| 主轴颈或主轴颈侧片 | 6/10 |
| 曲柄销 | **1/4** |
| 平衡重/曲柄臂 | 8/8，但结果只显示父级 `crankshaft`，不能归因 |
| 轴鼻、减振器、附件曲轴带轮 | 各 1/1 |
| 正时曲轴链轮 | **0/19** |

另有两个结构性缺口：正时链条被导出为 `camshaft`，附件皮带被导出为 `cooling-system`，二者均不在冻结扫描的动态件集合。因此“正时或附件传动 vs 无关壳体”是**未测**，不是通过。

V4 验收应按语义节点或明确机械角色扫描，达到曲轴 44/44、正时链轮 19/19，并纳入链条、皮带、相关带轮与无关壳体。预登记的链轮/链条、带轮/皮带有意接触可保留，但不得把无关壳体相交追加到白名单。

## 凸轮绕序与法线

两工具独立复现完全相同的 16 个凸轮节点，每节点 144 条绕序错误边，总计 2,304；8 个进气实例共用一个几何哈希，8 个排气实例共用另一个。它们依然水密、无非流形边、无退化面且总体有正体积，所以这不是“开洞”，而是相邻面在共享边上使用了相同方向。

只读源码定位到凸轮生成器：侧壁在前边界使用 `frontNext → front`，前盖也使用 `frontNext → front`；侧壁在后边界使用 `rear → rearNext`，后盖同样使用该方向。修复应仅反转两盖索引：前盖应为 `frontCenter, front, frontNext`，后盖应为 `rearCenter, rearNext, rear`。不能用 `DoubleSide`、重算法线或忽略检查掩盖索引错误。

验收：Trimesh 和 Blender 都报告 `totalWindingErrorEdges=0`、`totalInvalidGeometricNormals=0`，16/16 凸轮仍水密、正体积；全局退化面和重复面保持 0。

## 约 51% 重复顶点的归因

原始结果：Trimesh 为 51,546/100,712（51.1816%），Blender 为 51,518/100,684（51.1680%）。28 个顶点的导入器差异不影响任何拓扑裁决，不值得单独追逐。

对同位置点继续比较法线与 UV 后：

- 34,670（占重复数 67.2603%）是不同法线或 UV 组合所需的属性接缝；
- 16,876（占重复数 32.7397%，占全部 Trimesh 原始顶点 16.7567%）具有相同位置、法线和 UV，是可进一步索引的候选冗余；
- 18,916 个同位置组中，10,688 组同时有法线和 UV 差异，4,796 组仅 UV 不同，3,172 组仅法线不同，260 组没有观察到属性差异；
- 材质边界已被导出器拆成不同语义 primitive，因此本统计没有把跨材质节点强行焊接。

裁决：不能按位置焊掉“51%”。若 V4 要优化，只能按完整属性元组建立索引，并在未来存在 tangent、color、skin 等属性时把它们一并纳入。层级和实例边界不得跨越。

验收：同属性冗余显著下降或归零；法线/UV 接缝、硬边、材质边界、动画层级不变；同机位像素对比无可见退化；水密、绕序、退化面、重复面不回退。该项是 P2，优先级低于真实碰撞和凸轮索引。

## 缺陷清单与收益/成本/风险

### V4-GEO-01 — P1 — 主缸体、曲轴箱和缸套真实穿模

- 实证：上述 13 个 pair 的 Blender 721 点三角窄相；曲轴/主缸体 721/721，四根连杆/缸套各 272 个角。
- 影响：核心运动链在导出实体上机械矛盾，无法仅靠 X-Ray 可读性辩护。
- 收益：修复外部评测中最大的机械可信度缺口。
- 成本：高。
- 风险：重建壳体空腔和缸套避让可能破坏轮廓、剖切、材质、水密或帧率。
- 验收：同一 Blender 721 点表面扫描无未分类相交；不加白名单；运动学闭合、三模式画面和水密指标保持。

### V4-GEO-02 — P1 — 16 个凸轮盖面绕序错误

- 实证：两工具均为 16×144=2,304；源码索引方向可解析证明。
- 影响：法线/面方向不自洽，削弱拓扑可辩护性并可能导致单面渲染伪影。
- 收益：低成本、确定性消除跨工具缺陷。
- 成本：低。
- 风险：若只反错一侧，会得到反盖或负体积。
- 验收：两工具 0 绕序边、0 无效法线，水密和正体积不变。

### V4-GEO-03 — P1 — 曲轴、正时与附件扫描不可归因且漏覆盖

- 实证：44 个曲轴节点只覆盖 18 个；曲柄销 1/4；链轮 0/19；链条和附件带未进入动态集合。
- 影响：无法证明平衡重、轴颈、正时、附件与无关壳体间隙。
- 收益：把父级警报变成可修复的子件证据，避免漏掉真实干涉。
- 成本：中。
- 风险：扫描时间上升并暴露更多缺陷；这不是隐藏缺陷的理由。
- 验收：语义覆盖完整，每个失败能定位到子件，并保持冻结白名单不变。

### V4-GEO-04 — P2 — 同属性顶点冗余

- 实证：16,876 个位置/法线/UV 都相同的候选冗余。
- 影响：增加几何传输和顶点处理，但不是当前最大 Draw Call 或机械问题。
- 收益：理论上最多减少约 16.76% 原始顶点，同时保留已观察属性。
- 成本：中。
- 风险：漏纳入其他顶点属性会改变外观。
- 验收：完整属性索引、像素对比和拓扑回归全部通过。

### V4-GEO-05 — P2 — 碰撞量值命名过强

- 实证：冻结算法分别是最近外表面距离与径向超界，而非实体穿透求解。
- 影响：把代理量称为穿透深度会过度陈述测量能力。
- 收益：提高报告可信度且不隐藏实际三角相交。
- 成本：低。
- 风险：无；前提是保留原始值并附窄相证据。
- 验收：报告和 UI/工具把两值标为 proxy，不再称物理深度。

## 建议修改边界

主代理可考虑的高收益组合：

1. 修正凸轮两端盖索引顺序；
2. 把主缸体从“封闭外轮廓实体”重构为有四个缸孔、开放曲轴箱路径且保持外轮廓可读的程序化壳/结构件；
3. 由 720° 连杆扫掠包络与明确机械间隙导出缸套下端避让，不任意缩件；
4. 把曲轴、正时、附件评估拆成可定位的语义子件；
5. 只有在性能收益可测时，才对完整属性相同的顶点建立索引。

## 明确不实施的低收益或不合规做法

- 不为主缸体、缸套、正时或附件相交追加白名单；
- 不缩小、隐藏运动件，不关闭碰撞扫描，不用任意间隙刷分；
- 不按位置焊接全部 51% 重复点；
- 不为 28 个导入器顶点差异单独重写几何；
- 在没有正时/附件覆盖前不宣称它们无碰撞；
- 不把代理评分称为真人盲评，也不把本审查称为最终 V4 放行。
