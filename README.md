# INLINE · 4D

一个完全由源码程序化生成的四冲程直列四缸柴油机 3D 交互仿真。项目不包含下载的整机模型；主要尺寸、机械相位、零件元数据、材质和动画关系都可直接编辑。

## 运行

需要 Node.js 20 或更新版本。

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址。生产构建与预览：

```bash
npm run build
npm run preview
```

## 操作

- 左键拖动旋转，右键拖动平移，滚轮缩放；双击或按 `R` 复位。
- `Space` 暂停/继续；转速和负载滑块改变实时状态。
- 实体、X-Ray、剖切三种模式用于观察外部、透明壳体和运动链。
- `1`–`6` 切换轴测、前、侧、顶、曲轴和燃烧室预设；曲轴/燃烧室预设会自动选择合适的揭示模式。
- 悬停查看零件，点击锁定选择；右侧显示中英文名称、材料、制造、功能、参数和实时状态。
- 标签、流体路径和装配分解可独立开关。

## 源码结构

- `src/data`：可编辑发动机规格、运行范围和 18 类双语零件元数据。
- `src/engine`：精确滑块曲柄、720°四冲程相位、气门/喷油/燃烧包络与状态积分。
- `src/scene`：Three.js 程序化几何、装配、材质、灯光、流体、拾取、相机和观察模式。
- `src/ui`：完整仪表与控制界面。
- `tests`：运动学和流线边界回归测试。
- `docs`：架构、机械来源、浏览器测试和独立质量审查。

机械依据和建模假设详见 [`docs/MECHANICAL_RESEARCH.md`](docs/MECHANICAL_RESEARCH.md)，浏览器验收详见 [`docs/TEST_REPORT.md`](docs/TEST_REPORT.md)。
